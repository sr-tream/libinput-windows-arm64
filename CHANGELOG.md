# Changelog

## Initial public source snapshot

- Native Windows ARM64 scrolling adapter for the validated ASCE1200 touchpad.
- Four unchanged scrolling functions from libinput 1.32.0.
- Adjustable horizontal/vertical wheel scrolling and exponential momentum.
- Cancellation on real clicks, new two-finger touches and destination changes.
- Per-application Windows driver, Touchscreen and No gestures modes.
- English settings UI, executable picker and live application-profile reload.
- Touchscreen sensitivity, horizontal reversal and horizontal axis lock.
- Elevated login supervisor, emergency stop and separate panning watchdog.
- Source tests, an optional settings UI check, MIT licensing and build/setup documentation.
